# RedLine.surf

Холст для надписи **RedLine.surf** на графике активности профиля [Alast0rRL](https://github.com/Alast0rRL).

Каждое воскресенье workflow `Redraw` пересобирает историю этого репозитория:
на каждый «пиксель» надписи — 20 пустых коммитов с датой в прошлом, так что надпись
всегда стоит в окне «последние 12 месяцев».

- Текст, число коммитов на пиксель и часовой пояс — в начале `draw.py` (или через переменные `ART_*`).
- Перерисовать вручную: **Actions → Redraw → Run workflow**.
- Убрать надпись: удалить репозиторий.

> История перезаписывается force-push'ем — не храните здесь ничего ценного.
